# Adaptive prefill attention evidence

The default-off adaptive selector in this branch is reconciled onto `ef3e3df888d67b408d0e86be4c11aa473112dc27`, following the earlier scratch candidate `6ed6112e7a29af4f4619ac993eb795f9896ef0fc` based on `26566309186f8d50fc13770b1135f8a433e7afd7`. The base already contains the single-stage SIMT shared-memory fix (`a060db152c1bb799b943f77dd5c2d83d01a9d781`) and the separate Q8 tile launch-bounds fix. The selector is derived from draft [PR #36](https://github.com/zbrdc/fifi/pull/36), including its gated commit `e8ffc54a9ac066c683bd7d05ff83c7c00dd24f71`. The reconciled branch is a new source tree: earlier build and device results do not qualify it.

The original [observation record](../../scripts/benchmarks/qwen36-adaptive-attention-device-observations.json) records tests of `a552c9bf5df62387c0190c70b5d129dedfca0c52`. That candidate also contained tokenizer and health-test changes and was not the draft head. Its trace observations and test receipts apply only to that candidate; the record's statement that the then-current draft had not been device tested describes the time it was written.

Afterward, five isolated attention tests passed on the exact gated `e8ffc54` build with the switch on an RTX 2080 Ti and with the switch both on and off on an RTX 3080. The two segmented tests were explicitly included despite being ignored by default. The 2080 test binary SHA-256 was `9bf494fda6621a46bd02aede9aee71a1763f8ea78827538f2b2708ba8024702f`; the 3080 test binary SHA-256 was `5894c79f37b4b163949d9777f7263118c3f5e347c4cefca8664ab141b5331443`. Both services were restored after their runs. These are numerical checks, not dispatch traces or served-model parity; they do not measure speedup. An unrelated host-health test failed on the builds, and those runs did not establish green CI. The full receipts remain in the originating task scratch under `attention-gate-device/sm75/rotation-reserved-of6qi9rw`, `sm86/pair-reserved-vt996avo`, and `sm86-on/pair-reserved-baehfqeg`.

The e8 native build also contained sm89 code and compute89 PTX, but no RTX 40 or 50 board was tested. Long-context serving, other model geometries, dual-GPU behavior, and this reconciled tree still require their own evidence. The earlier measurements do not justify enabling the selector by default.
